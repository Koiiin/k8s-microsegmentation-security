# Rancher Server

Rancher Server được triển khai trên VM riêng bằng Docker.

## Thông tin lab

| Thuộc tính | Giá trị |
|---|---|
| Hostname | `rancher-server` |
| IP | `192.168.113.10` |
| Vai trò | Quản lý RKE2 cluster |
| Cách triển khai | Docker container |

## Lưu ý

Rancher UI có thể lên chậm sau reboot vì VM lab có RAM giới hạn.
